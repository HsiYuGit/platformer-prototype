# Movement Lab / 平台動作關卡實驗室

Godot 4.6.1 灰盒原型。目的：比較「一個移動技能 × 多種障礙型態」，不製作素材。

## 執行與操作

Godot 開啟 `project.godot`，F5 執行主場景；F6 可執行 `mechanics_lab.tscn`。
原始左右移動、可變跳高參數保留：速度 250、起跳 -400、重力 1000。
畫面使用 1280×720 虛擬座標，縮放維持比例。介面統一英文。

- A/D 或左右：移動；Space：跳躍（放開提早截斷）。
- X / Shift：專屬技能；R：重試 checkpoint；Esc：總入口。
- F1/F2/F3：直接選擇該關第 1/2/3 段；Enter：完成後繼續。
- B：開關技能做對照；切換時重置當段，避免帶入技能動量。
- 灰色：實體平台，紅色斜線：致死區，青色：起點，綠框：出口。
- 每段是一個 checkpoint，可獨立進入。通過出口後顯示結果，Enter 繼續。
- 總入口顯示本次執行的通關紀錄，關閉遊戲後清除。關閉技能的完成紀錄不算技能通關。

## 設計範圍

基準關只有左右與跳躍，作為操作校準。
規劃：衝刺、二段跳、蹬牆跳、滑翔、鉤索拉近、重力反轉，各三段幾何。
這六種是本次抽樣，不代表所有平台遊戲技能的完整分類。

## 結構

- `mechanics_lab.tscn` / `lab.gd`：總入口、checkpoint、重試、紀錄與 UI。
- `room.gd`：同一份幾何建立碰撞與繪圖。
- `player.gd` / `player.tscn`：方塊角色與共用物理，技能只在所屬關卡實例化。
- `levels/`：各關平台、危險區、教學、測試重點。
- `abilities/`：每關唯一技能。
- `tests/`：原生 Godot 驗證。

驗證記錄見 `docs/VALIDATION.md`。每一關含技能、幾何、文件與驗證，單獨 commit。

## 01 衝刺：次數與發動條件是獨立的設計軸

預設三段：一次衝刺寬坑、兩次衝刺接小島與再起跳、三次空中限定衝刺長坑。
衝刺 850 px/s、0.20 秒，固定水平方向、暫停垂直速度，兩次發動至少間隔 0.28 秒。
落地補滿；空中不會靠等待補充。撞牆會停止，不能穿越碰撞或紅色危險區。
按 C 在 1/2/3 次間切換，V 切換地面與空中／僅空中，會重置 checkpoint。
可在**相同幾何**交叉比較兩個規則軸，避免把地形差異誤當技能差異。
改過規則的完成不標記為預設通關；F1-F3 或換關恢復該段預設。

## 02 二段跳：高度、滯空距離、晚救回

Space 是地面跳，X 是每次離地後唯一的一次空中跳，起跳速度皆 -400。
三段分別為 130 px 高台、280 px 寬坑、帶低天花板的落差平台。
最後一段可直接走下平台，通過天花板後才補跳；技能不是必須先按 Space 才可用。
落地補充，空中連按不會無限上升。適合觀察「提早花掉資源」與「保留救回機會」的差異。

## 03 蹬牆跳：單牆攀爬、雙牆交替、階梯換牆

空中靠牆才可按 X，往牆外 310 px/s、向上 -440，0.14 秒方向鎖定避免立即抵銷反推。
持續朝牆移動時滑落速度上限 80。允許重新接觸同面牆後再跳，沒有額外攀爬技能。
三段測「同面牆重複操作」、「狹井左右交替」、「站上中途牆頂後換牆」。
可觀察自動滑牆是否太寬容、短暫方向鎖定是否影響手感。

蹬牆包含 0.10 秒離牆容許，支援轉向與技能幾乎同時按下。狹井頂端有可見天花板，接近出口高度時最後一次蹬牆後轉向右側。
